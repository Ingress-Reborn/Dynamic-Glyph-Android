# Glyph Lens 0.4.3：全流程特征识别

更新日期：2026-11-09。

**本轮移除全部 OCR，识别阶段改用槽位高亮变迁、点阵和输入计时条的像素特征。** 删除 ML Kit、Latin/中文/日文/韩文四类模型、阶段标题读取与游戏语言设置。Glyph 形状匹配、序列预测和 CSV 数据沿用已有实现，地图五目标自动隐藏继续保持。

版本为 **0.4.3 / versionCode 7**，生产源码为 **`6fea790`**。本轮 **11 项重点 JVM 测试、2 项正式 APK 双轮流程及 10 张关键截图人工核对通过**；本地 APK 为 **417,845 bytes**，比 0.4.2 小 **97.36%**。0.4.2 原始证据继续保留在 [VISUAL_COMPLETION.md](VISUAL_COMPLETION.md)，不继承为本版通过。用户八条规则原文见 [Plan.md](../Plan.md#2-强制通用规则)。

## 1. 当前范围

| 部分 | 0.4.3 行为 |
| --- | --- |
| 阶段输入 | 只使用槽位高亮及其变迁、点阵可见性和输入计时条；不读取标题或其他文字 |
| Glyph 识别 | 11 节点标定、固定采样、线段/形状匹配与跨帧确认保持 |
| 输入阶段 | 由实际像素特征进入输入并冻结本轮序列；玩家笔画不能新增或改写展示 Glyph |
| 下一轮 | 由新的槽位与点阵展示特征恢复识别，不等待标题或语言切换 |
| 预测 | 连续已确认前缀、已知槽位数和原序列表；唯一与歧义处理保持 |
| 地图隐藏 | 五个独立地图目标任一命中时按现有选项隐藏；地图信号不代表成功 COMPLETED |
| OCR / 语言 | 删除阶段 OCR、ML Kit、四类随包模型和游戏语言设置，不保留 OCR 兜底 |
| 数据 | 不重写预测、不修改 CSV 内容或导入语义 |

阶段判断来自特征的组合与变化顺序，不能仅因为点阵暂时消失就认定新轮或完成。这里不新增复杂的猜测性边界处理；按仓库现有状态追踪实现调整真正受影响的输入与转换。

删除 OCR 后同时清理仅服务于它的依赖、模型、语言选项、请求调度和相关代码，移除 ProGuard 中的 OCR 专属规则。APK 不再包含 OCR 原生库；保留现有 NDK arm64 配置，不为强制 ABI 添加空库。R8 和现有原生 Android 工程继续使用，不引入替代 OCR、推理模型、OpenCV 或新的构建/验证工具。

## 2. 保持的用户操作

实时模式授权后自动后台识别，初始无窗口或图标；省电模式点击图标后开始。已确认前缀加唯一预测覆盖整组，或全组真实确认后，沿用每轮自动显示规则。预测仍与真实确认分开呈现。

“返回地图后自动隐藏”保持可选、默认关闭。开启时仅显示可拖动画布，移除顶部 × 整行；五个地图目标为菱形/指南针、信号弧、叠层、方框加号和公文包，任意一个命中即可隐藏。地图上通过通知手动显示后，目标仍存在就再次隐藏。

关闭自动隐藏时，实时 × 隐藏且继续识别，省电 × 停止并回图标。通知“显示悬浮窗”和“停止”、同授权持续识别和下一轮恢复均沿用现有流程。去除游戏语言设置不影响画布大小、清晰度及 CSV 导入设置。

## 5. 历史与范围边界

0.4.2 已发布到原仓库并完成目标 main 同步，下载验证与标签/生产提交记录保留在原专项文档中；这是既有历史结果，不是本轮重新执行的流程，也不把旧包链接描述为 0.4.3 产物。

交付目标仍为 Android 10 以上的 arm64、竖屏整屏共享，不增加其他架构产物。旧版的分辨率矩阵只证明对应旧包；本轮增量验证通过不等于所有实体机、横屏、分屏或单应用共享已经认证。
